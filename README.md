# ربات تلگرام دانلود یوتیوب + زیرنویس فارسی چسبیده

لینک ویدیوی یوتیوب رو برای ربات بفرست، ربات ویدیو رو دانلود می‌کند، با Whisper گفتار را به متن تبدیل می‌کند، متن را به فارسی ترجمه می‌کند، زیرنویس فارسی را با ffmpeg روی ویدیو می‌چسباند (burn-in) و یک **لینک دانلود مستقیم** در تلگرام برایت می‌فرستد.

> چرا لینک به‌جای فایل؟ Bot API معمولی تلگرام اجازهٔ ارسال فایل بیشتر از ۵۰ مگابایت را نمی‌دهد، در حالی که ویدیوهای با زیرنویس چسبیده معمولاً بزرگ‌تر از این هستند. برای همین ربات فایل نهایی را روی یک وب‌سرور ساده (کنار همین پروژه، با nginx) سرو می‌کند و فقط لینکش را در چت می‌فرستد.

## پیش‌نیاز مشترک

- توکن بات از [@BotFather](https://t.me/BotFather)
- یک آدرس عمومی (دامنه یا IP سرور) که بتوانی روی آن یک پورت (پیش‌فرض `8080`) را به بیرون باز کنی، چون لینک دانلود باید از گوشی/کامپیوتر کاربر در تلگرام قابل‌دسترس باشد — نه فقط از `localhost`.

## اجرا با Docker (توصیه‌شده)

با این روش نیازی به نصب Python، ffmpeg یا فونت فارسی روی سیستم نیست؛ همه چیز داخل ایمیج ساخته می‌شود.

پیش‌نیاز: Docker و Docker Compose نصب باشند.

```bash
cd yt-persian-sub-bot
cp .env.example .env
```

توکن بات و آدرس عمومی سرور را داخل `.env` قرار بده:

```
BOT_TOKEN=123456:ABC-your-token
PUBLIC_BASE_URL=http://SERVER_IP:8080
```

اگر پشت یک دامنه/ریورس‌پراکسی (مثل Caddy یا nginx با TLS) هستی، به‌جای باز کردن پورت ۸۰۸۰ مستقیم، آن دامنه را داخل `PUBLIC_BASE_URL` بگذار و سرویس `files` را فقط از طریق آن ریورس‌پراکسی در دسترس بگذار.

بعد بساز و اجرا کن:

```bash
docker compose up -d --build
```

### اگر یوتیوب درخواست ورود کرد

ایمیج Docker شامل Deno و بستهٔ `yt-dlp-ejs` است که برای چالش‌های JavaScript یوتیوب لازم‌اند. با این حال، یوتیوب ممکن است IP سرور را به تأیید ورود وادار کند. در آن صورت، یک فایل کوکی با قالب Netscape/Mozilla از نشست یوتیوب خود صادر کن و روی سرور در `secrets/youtube-cookies.txt` قرار بده. [راهنمای رسمی yt-dlp برای کوکی‌های یوتیوب](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies) را برای روش صدور و نکات مربوط به نشست بخوان. استفاده از کوکی حساب ممکن است باعث محدودیت یا مسدود شدن حساب شود؛ فقط در صورت نیاز از آن استفاده کن.

```bash
mkdir -p secrets
# فایل کوکی صادرشده را به secrets/youtube-cookies.txt منتقل کن
chmod 600 secrets/youtube-cookies.txt
```

سپس این خط را به `.env` اضافه کن و سرویس را دوباره بساز:

```dotenv
YT_DLP_COOKIES_FILE=/run/secrets/youtube-cookies.txt
```

```bash
docker compose up -d --build
```

فایل `secrets/` داخل ایمیج Docker کپی نمی‌شود و در git هم نادیده گرفته می‌شود؛ Compose آن را فقط برای خواندن در کانتینر قرار می‌دهد. ربات برای استفادهٔ yt-dlp یک کپی موقت می‌سازد و پس از هر درخواست پاک می‌کند. فایل کوکی را به کسی نفرست و در مخزن ثبت نکن. کوکی‌های منقضی‌شده باید دوباره صادر شوند. اگر چالش حتی با کوکی تازه ادامه داشت، ممکن است IP سرور از طرف یوتیوب محدود شده باشد.

لاگ‌ها:

```bash
docker compose logs -f
```

توقف:

```bash
docker compose down
```

نکات مربوط به دیتا:
- فایل‌های موقت دانلود داخل پوشهٔ `downloads/` و ویدیوهای نهایی (همان‌هایی که لینکشان فرستاده می‌شود) داخل پوشهٔ `public/` کنار پروژه ذخیره می‌شوند؛ یک سرویس جدا به نام `files` (nginx) همین پوشهٔ `public/` را روی پورت `8080` سرو می‌کند.
- مدل Whisper در یک volume به نام `whisper-cache` نگه داشته می‌شود تا هر بار کانتینر بالا می‌آید دوباره دانلود نشود.
- فایل‌های داخل `public/` به‌صورت خودکار بعد از `FILE_RETENTION_HOURS` ساعت پاک می‌شوند (یک job داخلی هر یک ساعت این پاک‌سازی را انجام می‌دهد).
- لینک‌ها فقط با یک شناسهٔ تصادفی محافظت می‌شوند، نه با رمز؛ یعنی هرکس لینک را داشته باشد می‌تواند فایل را دانلود کند. اگر این موضوع برایت حساس است، سرویس `files` را پشت یک ریورس‌پراکسی با احراز هویت بگذار.
- برای ویرایش تنظیمات (مثل اندازهٔ مدل Whisper) کافیست `.env` را عوض کنی و `docker compose up -d --build` را دوباره بزنی.

## اجرای مستقیم بدون Docker (اختیاری)

اگر ترجیح می‌دهی بدون Docker اجرا کنی:

- Python 3.10+
- ffmpeg نصب‌شده روی سیستم و قابل‌دسترس در PATH (باید `libass` داشته باشد؛ بیلدهای رسمی ffmpeg این را دارند)
- یک فونت فارسی نصب‌شده که fontconfig بشناسدش، مثلاً [Vazirmatn](https://github.com/rastikerdar/vazirmatn) (برای راست‌به‌چپ و شکل درست حروف فارسی لازم است)

```bash
cd yt-persian-sub-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

توکن بات را داخل `.env` قرار بده، سپس:

```bash
python bot.py
```

سپس در تلگرام با ربات `/start` بزن و یک لینک یوتیوب برایش بفرست.

## تنظیمات (در فایل `.env`)

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `WHISPER_MODEL_SIZE` | اندازه مدل Whisper (`tiny`/`base`/`small`/`medium`/`large-v3`) — بزرگ‌تر یعنی دقیق‌تر ولی کندتر | `small` |
| `WHISPER_DEVICE` | `cpu` یا `cuda` (اگر GPU نویدیا و cuDNN داری) | `cpu` |
| `MAX_VIDEO_MINUTES` | حداکثر طول ویدیوی قابل‌قبول | `20` |
| `MAX_VIDEO_HEIGHT` | کیفیت دانلود برای کنترل حجم فایل خروجی | `720` |
| `SUBTITLE_FONT` | نام فونتی که ffmpeg برای زیرنویس استفاده می‌کند | `Vazirmatn` |
| `MAX_CONCURRENT_JOBS` | تعداد پردازش هم‌زمان مجاز | `1` |
| `PUBLIC_BASE_URL` | آدرسی که وب‌سرور فایل‌ها (`files`/nginx) از بیرون در دسترس است؛ لینک‌های ارسالی با همین پیشوند ساخته می‌شوند | *(باید تنظیم شود)* |
| `FILE_RETENTION_HOURS` | چند ساعت بعد از ساخت، فایل‌های داخل `public/` پاک شوند | `24` |
| `YT_DLP_COOKIES_FILE` | مسیر فایل کوکی در قالب Netscape/Mozilla؛ در Docker از `/run/secrets/youtube-cookies.txt` استفاده کن | *(خالی؛ بدون کوکی)* |

## محدودیت‌ها و نکات

- **حجم فایل:** به همین دلیل که Bot API معمولی تلگرام اجازهٔ ارسال فایل بیشتر از ۵۰ مگابایت را نمی‌دهد، ربات فایل نهایی را سرو می‌کند و فقط لینکش را می‌فرستد؛ خودت باید مطمئن شوی `PUBLIC_BASE_URL` از اینترنت در دسترس است (پورت باز، یا پشت دامنه/ریورس‌پراکسی).
- **سرعت:** تبدیل گفتار به متن روی CPU برای ویدیوهای طولانی می‌تواند چند دقیقه طول بکشد؛ مدل `small` یا `base` برای شروع مناسب‌ترند.
- **کیفیت ترجمه:** ترجمه با Google Translate (از طریق `deep-translator`) انجام می‌شود و رایگان است، اما ممکن است گاهی محدودیت نرخ درخواست بخورد یا ترجمه کاملاً روان نباشد.
- **حقوقی:** این ابزار را فقط برای محتوایی استفاده کن که اجازهٔ دانلود/استفادهٔ شخصی یا آموزشی آن را داری و قوانین و شرایط استفادهٔ یوتیوب را در نظر بگیر.

## ساختار پروژه

```
config.py       تنظیمات از روی متغیرهای محیطی
utils.py        تشخیص لینک یوتیوب در متن پیام
downloader.py   دانلود ویدیو با yt-dlp
subtitles.py    تولید زیرنویس با faster-whisper + ترجمه به فارسی
burner.py       چسباندن زیرنویس به ویدیو با ffmpeg
cleanup.py      پاک‌سازی دوره‌ای فایل‌های قدیمی از public/
bot.py          هندلرهای ربات تلگرام
Dockerfile      ایمیج شامل Python + ffmpeg + فونت Vazirmatn
docker-compose.yml   اجرای ربات با یک دستور
```
